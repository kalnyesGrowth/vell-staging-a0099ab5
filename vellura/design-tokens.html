Fonts
Heading: Sentient · Body: General Sans, both from Fontshare.
Web licence: Fontshare / Indian Type Foundry Free Font License. Free for commercial use, web embedding permitted, no purchase or attribution required. Self-host or CDN both allowed. Verify at fontshare.com/licenses before launch.

Icons: no icon set is used. Every mark in these screens is CSS or a text character, so there is nothing to license or export. If the store's design system brings its own icon set, it drops in without conflict.

Type scale: Minor Third (1.200), 16px base. Headings clamp on mobile.

The two colors you must not swap
--pause (amber) and --error (red) carry meaning, not brand. E-03 is a pause and E-04 is a decline, and per the brief those two things must never look alike. If the store palette overrides them into the same family, the exit states stop communicating and support volume goes up.
